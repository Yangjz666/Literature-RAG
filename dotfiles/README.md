# Editor Setup

This folder mirrors the local Neovim and Yazi configuration installed for this
workspace.

- `nvim/` -> `%LOCALAPPDATA%\nvim`
- `yazi/` -> `%APPDATA%\yazi\config`

Main bindings:

- `<leader>gg`: open Lazygit
- `<leader>e`: open Yazi
- `<leader>fp`: file picker with preview
- `<leader>sg`: grep picker with preview
- `<leader>md`: toggle inline Markdown rendering
- `<leader>mg`: open Markdown preview with Glow
